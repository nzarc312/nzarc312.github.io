Project: Robot Recyclers

A dynamic Unity WebGL game built around multiple interacting modular systems. The project features a custom hybrid AI architecture that combines a Stack-Based Finite State Machine (FSM) with a Utility-based action selection system. This allows enemy agents to dynamically evaluate combat variables and prioritize complex behaviors—such as maintaining distance, strafing, or protecting vulnerable allies. The architecture heavily leverages ScriptableObjects to create highly decoupled, scalable combat and behavior states.
